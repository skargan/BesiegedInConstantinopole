APPROVED RULES AND IMPLEMENTATION
1. Fixed milestones run before due narrative follow-ups; deferred follow-ups keep their pending state. Ordinary narrative selection remains one main event per day; existing immediate linked consequences remain possible. This is not a new general-purpose event queue.
2. Fleet income/report runs every 14 active siege days, independently of random narrative selection. Changing missions restarts that cycle. Harbour defence and urgent reports keep their existing immediate behaviour. Fourteen days is a gameplay decision, not an asserted historical reporting rule. Existing reward amounts have not been rebalanced; send this cadence change to balance testing.
3. Aid has explicit sea/land routing. Storms target only incoming sea aid. Land appeals no longer require a ship; sea appeals retain the existing available-ship requirement.
4. New ordinary aid appeals promise zero player warships. Transports go home. Explicit saved iAidWarshipsN commitments are delivered exactly once. Legacy pending aid without that field honours its old ship pledge. A separate explicit warship negotiation interface is still to be designed; data support is not a claim that it exists.
5. Commander preparation adds ten actual army morale points once when a commander is appointed, rather than writing an unused support stat. Existing completed saves are not retrospectively compensated.
6. Galata credit is a ten-year loan: gold now, no repayment during this siege. Old bookkeeping values remain compatible; labels no longer imply a current repayment obligation.
7. Surrender pressure uses lost defensive depth: (100 per lost line + damage to the current line) / 3. Fury and camp alert keep their previous separate weights. Losing a wall and reaching a fresh next wall cannot reduce pressure.

DEFAULT ROUTES
Land: Hungary, Albania, Holy Roman Empire, Poland-Lithuania, Teutonic Order.

These are authored expedition routes, not universal claims about a country's geography. Future negotiated routes should store the route on each expedition.
