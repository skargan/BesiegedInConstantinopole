# Version 39 — Consolidated Windows playtest

Download **Besieged-Version-39-Windows-x64.zip**, extract the whole folder and run **Besieged.exe**. Unity is not required. Keep the executable beside Besieged_Data and MonoBleedingEdge. The source-code ZIP is for developers, not the playable download.

## Included

- Shared physical provisions, fractional stocks, provincial reserves and fortnightly deliveries; escalating city hunger and Ottoman desertion.
- Compact technology desk with workshop background, selected technology illustration, visible secrets and a 50/50 starting care/research allocation.
- Ionian Isles court, Raimondina's approved dialogue, refuge agreements, journal records and ending references.
- Saved daily incidental dialogue limits and pacing for Raimondina and the grain merchant.
- 74 additional event-art mappings using 64 original images, bringing coverage to 132 event nodes while preserving existing art overrides.
- Provincial battle illustrations, inset event-image framing, diplomatic attitude badges and sea-token presentation corrections.
- Imperial Council chamber, Decision Journal, journal icon, clearer wall-repair presentation, centred status strip and campaign-start menu improvements.
- Consolidated source and an indexed future-development archive; obsolete prototypes are preserved without reactivating retired mechanics.

## Playing and saves

Normal campaigns allow named saves. Ironman uses a rolling save and enables achievements. Settings include fullscreen/windowed mode and optional assault minigames. Development options remain available in this playtest.

Campaign archives are stored in the local **Saves** folder. Extract into a writable folder such as Games or Documents. No developer campaign saves are included. Start a fresh campaign for this playtest; older food-state migrations and long-campaign balance have not been comprehensively certified. Keep any older saves separately.

## Verification and limits

Built with Unity 2022.3.15f1 for Windows 64-bit. The exported player passed provisions/save-load (149), technology desk (11,277), Ionian court (188), chatter (198), art integration (3,723), event frames (8,294), provincial art (104), and chamber/journal/navigation (106) assertions. The editor assault regression suite also passed. These are focused assertions, not numbers of complete campaigns. Representative technology, Ionian and event-art screens were visually reviewed. No new 200-campaign balance study or broad hardware benchmark is claimed.

This is a development playtest, with unfinished balancing and content. Older Emperor XP, court quests, murder investigations, Candar/Ragusa staging and Malta mercenary DLC remain outside this release; see FutureDevelopment/README.md in the source repository. The expanded five-choice Our Turks rewrite remains outstanding.
