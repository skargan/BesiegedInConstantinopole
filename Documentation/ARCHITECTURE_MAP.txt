BESIEGED ARCHITECTURE MAP - consolidation pass 22 October 2026

AUTHORITIES
Campaign: Assets/Scripts/VariableSingleton.cs dictionaries and CampaignSave version2 (individual population). Legacy string keys are compatibility interfaces for Yarn, not permission to create a parallel state store. Preserve key names and units during migration.
Encounter: PhasedAssault owns the temporary assault snapshot, seeded RNG, permitted phase transitions and once-only actions. Phase = Approach / Contact / Aftermath. The six screen breadcrumbs are presentation subdivisions, not six independent simulations.
Resolved encounter: AssaultResult is a frozen snapshot. AI.CommitPhased is the campaign adapter. TryCommit permits one application, and practice exits before campaign mutation. Report and campaign deltas read this same snapshot. Public legacy model fields remain a staged encapsulation debt, not a second authoritative result.
Content: Assets/Resources/Content/AssaultIncidents.json is the sole assault incident definition source, schema1. Each incident has stable Id, phase, condition, prose and choices with costs/effects. Loader checks schema, unique IDs, conditions, choices and a resource-free fallback. Documentation/Assault incident catalogue.json is a pointer only. Yarn remains authoritative for narrative events; do not migrate everything to another format.
Presentation: PhasedAssaultUI, BattleCrowdView, AssaultDuelUI, LadderDefenceUI and SceneParticles render/input. PresentationRandom and local System.Random instances sample cosmetics; they do not advance Unity's saved campaign random stream.
Time: campaign turn/calendar lives in VariableSingleton; simulated fighting seconds in PhasedAssault are distinct from UI countdown/animation seconds. Reading and pausing do not create simulated casualties.

INTERFACES
AI.BeginPhased -> snapshot + PopulateDisposition -> PhasedAssaultUI.
UI combat intents -> model actions or AssaultIncidents.Choose -> model changes.
Model Resolve -> frozen Outcome + Resolved notification -> AI.CommitPhased -> campaign updates + report.
AssaultPractice creates disposable snapshots and returns without campaign updates. Resource and calendar isolation is tested in exported-player smoke tests.
DefencePosture calculates land/sea allocation from the current campaign totals. RefreshDisposition now recalculates existing snapshot fields directly before combat; it does not create another battle, alter UI or consume a new seed.
