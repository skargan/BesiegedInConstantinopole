# Against Fate: Saving Constantinople — Version 39.1

A content completion update to Version 39. Run **Saving Constantinople.exe** beside its accompanying folders.

## Changes

- New full title and shorter Saving Constantinople identity, with legacy preference and save identifiers preserved.
- Expanded Our Turks preparation event: five mutually exclusive rulings; Mobilisation and Diplomacy gates; Orhan availability and loyalty; Turkish Battalion journal entry; confidential infiltration consequences and visible screening interception.
- Evening in a Tavern: four choices, chance outcomes and a delayed volunteer pledge, using the existing daily-event scheduler.
- Replacement Giustiniani full-height figure, portrait and arrival illustration.
- Six cause-specific defeat illustrations: army, public, noble and clergy collapse, conquest and assassination. Existing defeat precedence retained.
- Nine approved calm launch illustrations, selected once per application session independently of campaign randomness (JohanX).
- Version 39's existing event-art coverage remains included; archived prototypes and mercenary DLC are not activated.
