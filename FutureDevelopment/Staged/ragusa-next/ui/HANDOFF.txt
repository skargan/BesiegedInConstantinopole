Entry point: CouncilUI.RagusanCourt().
RagusaText.Get(string key, string fallback="") exposes every prose passage.
RagusaText.Data contains characters, hover remarks, realm profile and scene polygons.
The single resource uses serializable arrays/objects compatible with JsonUtility.
Canonical prose and polygons are copied without editing from writing/ and art/.
prepare_authoring_data.py rebuilds the resource and validates counts.

The artwork is fitted, never stretched or cropped. Its hotspot coordinates share
that exact fitted rectangle. Rear silhouette is created first; foreground wins
the hit test where the robes overlap. Gold outline uses existing LocationHotspot.
The fixed right panel occupies 36.5% of the painting. The main menu has no scroll.
Only long reviews and profiles receive an independently clipped reading panel.
Both visible character buttons provide the same profile action as their silhouettes.
Focus and pointer entry show a line; pointer movement does not change the line.
Local cosmetic counters never consume UnityEngine.Random or write campaign state.

Provision and troop-contract buttons first show all material terms. Confirm is
MakeTurnButton -> RagusaDiplomacy -> existing Finish(success, report), retaining
major-action and outcome behaviour. Cancel/Return and reading have no action cost.
Failed backend validation leaves the screen open and displays its actual reason.
The dedicated court does not expose generic aid, renewed aid or generic war entry.
Existing envoy dispatch/recall reviews are retained in a compact final button.
